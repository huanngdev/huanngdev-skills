# Internal packages & shared configs

## Internal packages: compiled with tsdown
Every package in `packages/` (except `packages/config`) builds with tsdown (Rolldown + Oxc): fast rebuilds, errors caught at build time, plain imports for apps.
```json
{
  "name": "@<scope>/shared",
  "private": true,
  "version": "0.0.0",
  "type": "module",
  "scripts": {
    "dev": "tsdown --watch",
    "build": "tsdown",
    "check-types": "tsc --noEmit",
    "lint": "oxlint --type-aware --deny-warnings",
    "test": "bun --bun vitest run"
  }
}
```
```ts
// tsdown.config.ts
import { defineConfig } from "tsdown";
export default defineConfig({ entry: ["src/index.ts", "src/server.ts", "src/client.ts"], dts: true, exports: true });
```
- `exports: true` makes tsdown write the `exports` map into package.json, pointing at whatever files it emits in `dist/`. Don't hand-edit it or assume file extensions; add an entry point in `tsdown.config.ts` instead.
- tsconfig preset for packages enables `isolatedDeclarations`: exported functions need explicit return types, and declarations are generated by Oxc (fast). A missing type fails the build.
- Apps depend with `"@<scope>/shared": "workspace:*"` and import `@<scope>/shared` or `@<scope>/shared/server` — never `src/` or `dist/` paths.
- In dev, `bun run dev` builds packages once, then `tsdown --watch` rebuilds on save while apps run.
- Separate server-only and client-safe entry points so bundles stay clean.
- `packages/config` is the exception: JSON presets + config files loaded by tools, no build.

## Lint / format / tsconfig / test config live in `packages/config`
```
packages/config/
  tsconfig/base.json, package.json (isolatedDeclarations), vite-react.json, bun.json
  oxlint/base.json, react.json, node.json
  oxfmt.json
  vitest/base.ts
```
- tsconfig: app `tsconfig.json` = `"extends": "@<scope>/config/tsconfig/<preset>.json"` + includes only.
- oxlint: `extends` takes **relative file paths** (not package names). App `.oxlintrc.json` = `{ "extends": ["../../packages/config/oxlint/react.json"] }`. Script `"lint": "oxlint --type-aware --deny-warnings"` (type-aware options go on the CLI, not in nested configs).
- oxfmt: one config for the whole repo, run from the root with `-c packages/config/oxfmt.json`. No `.oxfmtrc.*` in apps.
- vitest: app `vitest.config.ts` = `mergeConfig(base, { … })` importing `@<scope>/config/vitest/base`.
- Need a different rule for one app? Add/adjust a preset in `packages/config`. Never inline rules in an app.
