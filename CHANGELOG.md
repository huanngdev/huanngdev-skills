# Changelog

All notable changes to the `huanngdev` plugin. Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), versioning: [SemVer](https://semver.org/) — rules in [AGENTS.md §7](AGENTS.md#7-versioning).

## [Unreleased]

### Added
- `hd-index`: entry-point skill with global rules (challenge the user, Bun-first, engineering defaults, language) and the skill map.
- `hd-index`: Oxc/Vite toolchain (oxlint, oxfmt, Vite, Vitest) and tests in a separate `test/` folder.
- `hd-infra`: monorepo (Turborepo + Bun, internal packages built with tsdown (watch in dev, isolatedDeclarations), type-aware oxlint, `packages/config` for tsconfig/oxlint/oxfmt/Vitest, turbo.json cache limits + TUI, `vercel/turborepo` vendor skill), Docker Compose (root `.env` for compose, per-app `.env`, secrets generated by `assets/gen-env.ts`), CI (GitHub Actions baseline).
- `hd-backend`: Hono + Bun API layering (route → service → repository, mappers), shared error/response shapes, cursor pagination, PostgreSQL 18 + Drizzle (Bun.sql, uuidv7, migrations, transactions, faker seeds), MinIO via `Bun.S3Client`, Redis via `Bun.redis`.
- `hd-validate`: Zod everywhere, shared schemas, mandatory env validation, forms; Zod docs MCP.
- `hd-auth`: Better Auth conventions, Hono mounting, sessions, permissions in services; Better Auth docs MCP and official skill.
- `hd-ai`: AI SDK + OpenRouter defaults, structured output, safety, mock-model tests.
- `hd-infra`: tests run with `bun --bun vitest run`; standard compose services.
- `hd-index`: docs-research rule and a single docs-sources registry (docs MCP, official skills, llms.txt per tech); every skill points to it with one standard line.
